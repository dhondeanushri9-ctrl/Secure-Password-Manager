# Secure Password Manager Using Hashing

**Category:** Multidisciplinary  
**Sustainable Development Goal (SDG):** SDG 9 – Industry, Innovation and Infrastructure

## Project Description

The Secure Password Manager Using Hashing is a Python-based software application designed to provide secure user registration and login authentication using cryptographic hashing. The system uses the Argon2id password-hashing algorithm to convert passwords into secure hash values before storing them, ensuring that original passwords are not stored directly.

The application provides an interactive web interface where users can register an account, log in using their credentials, and view the stored password hashes for demonstration purposes. It uses a hash table implemented through Python dictionaries to store and retrieve user information efficiently. The system also verifies passwords during login and displays appropriate messages for successful authentication, incorrect passwords, and duplicate usernames.

This project demonstrates the practical application of data structures, hashing algorithms, collision handling concepts, and cybersecurity principles. It aims to promote secure authentication practices and improve awareness of password protection in modern software systems.

## Key Features

- User registration and login verification.
- Secure password hashing using Argon2id.
- Hash-table-based username lookup.
- Password validation and duplicate username detection.
- Interactive web interface using Python and Gradio.
- Display of stored password hashes for educational demonstration.

## Expected Outcome

The project provides a simple demonstration of how password hashing can improve account security. It combines data structures and cybersecurity concepts to develop a practical authentication application aligned with SDG 9, which promotes innovation and resilient technological infrastructure.
